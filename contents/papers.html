Codes

I am a co-developer of the PhaseSpaceDTFE.jl Julia package for evaluating multistream density and velocity fields from cosmological N-body simulations. The code is hosted at this repository and registered with the DOI 10.5281/zenodo.16637560. Have a look at the documentation if you’re interested in using the code in your own research, and do not hesitate to reach out to the developers if you have any questions!

I am the lead developer of the DiscreteNaturalNeighbors.jl, a Julia package that implements a discretised version of natural neighbor interpolation (also known as Sibson interpolation) for data on unstructured grids in n dimensions. Following the method of Park et al. (2006), it replaces Voronoi tessellations with discretised in-cell counts. This makes the method highly efficient, rendering natural neighbor interpolation applicable to problems with a large number of data points, such as millions of particles in cosmological simulations. Have a look at the documentation!
